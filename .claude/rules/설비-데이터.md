# 설비 데이터 규칙 (data/ 안 파일을 다룰 때)

- `data/`의 샘플 파일(`equipment-status.txt`, `alarm-history.txt`)은 화면에서 수정·삭제하지 않는다. 새 샘플이 필요하면 생성 스크립트로 다시 만든다.
- `equipment-status.txt`는 18개 설비의 현재 상태 스냅샷, `alarm-history.txt`는 알람·멈춤 이력 로그로 분리해서 유지한다 (요구 건수가 서로 다르기 때문).
- 상태가 멈춤·알람인 레코드는 원인(cause)이 반드시 있어야 한다 (100자 이내).
- 상태가 알람인 레코드는 조치 상태(actionStatus)가 반드시 있어야 한다 (확인전/확인중/조치완료/조치불가 추가 확인 필요).
- 비고(조치 내용)는 150자 이내다.
- 데이터 형식은 파이프(`|`) 구분 텍스트를 유지한다 (JSON으로 바꾸지 않는다).
- 점검자 입력·OK/NG 판정·저장 기능은 이 프로젝트 범위에 없다 — `data/`는 항상 읽기 전용 샘플이다.
